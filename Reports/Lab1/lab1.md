ГОСТ 28147-89 -- блочный алгоритм шифрования, основанный на сети Фейстеля. На вход алгоримта подается 64 битный блок открытого текста и 256 битный ключ.

Сеть Фейстеля -- метод построения блочного шифра, при котором блок делится на две половины, и на каждом такте новая левая половина образуется XOR'ом правой половины с результатом функции раунда над левой половиной, а новая правая половина равна значению старой левой.

# Расписание ключей

Ключ разбивается на 8 32-битных подключей. Т.к. раундов в алгоритме 32 и на каждый раунд нужен ключ, необходимо 32 подключа.

- При зашифровании первые 3 блока по 8 ключей используются в прямом порядке (K_0 ... K_7), а последние 8 ключей идут в обратном порядке (K_7 ... K_0)

- При расшифровании первые 8 ключей идут в прямом порядке (K_0 ... K_7), а оставшиеся 24 ключаа в обратном порядке.

# Функция раунда

На вход подается левая половина блока открытого текста и подключ текущего раунда. Подключ разбивается на восемь 4-битных частей.

Каждая часть заменяется на значение из s-блока.
Части склеиваются в обратно в 32-битное слово, затем выполняется циклический сдвиг влево на 11 бит.

# Простая замена, ecb

По стандарту длина данных должна быть кратна 8 байтам.

Если длина данных не кратна 8, выполняется дополнение по PKCS#7 (не по стандарту, просто для удобства)

Затем выполняется зашифрование данных блоками по 64 бита.

# Гаммирование

Для вычисления гаммы необходима синхропосылка(iv), ключ и длина открытого текста. Синхропосылка шифруется простой заменой и результат записывается в n3 и n4.

n3 суммируется по модулю 2^32 с 0x01010101
n4 суммируется по модулю 2^32-1 с 0x01010104

далее n3 и n4 собираются в 64 битный блок и зашифровываются, результат является 64 битами гаммы. Эти шаги повторяются пока длина гаммы не превысит длину открытого текста.
